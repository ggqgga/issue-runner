reference·"이 심볼이 다른 곳에서 아직 참조되나" 같은 판정은 동봉된 diff 만으로는

diff-바깥 사실에 근거한 지적은 **BLOCKER 로 올리지 말고 WARN 으로 내려** 사유에
`diff만으로 확인 불가 — 나머지 코드베이스 미확인` 을 명시하라.
diff 범위 안에서 자체 모순(추가한 호출의 정의가 없음 등)이 보이는 경우에만
BLOCKER 로 판정한다.
