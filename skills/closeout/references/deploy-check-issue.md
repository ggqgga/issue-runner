## 완료 처리
위 체크박스를 전부 밟으면 이 이슈를 닫는다. 배포 뒤에도 `- [ ]` 가 남아 있으면 deploy-cycle ⑤ 가 그 줄을 `테스트` 이슈로 옮기고 이 이슈를 닫는다. `[dev]` 표식 줄(m2 dev 판정)은 배포 전 BoDAT dev 회차가 밟고, 못 밟았으면 같은 `테스트` 이슈로 넘어간다. 실장비 줄(접두 표식 `[칸 ③-prod]` — 옛 `[칸 ③]` 포함, 운영 TEST 워커 프로필 #18)과 (다른 레포의) 표식 없는 줄은 배포 뒤 BoDAT e2e-test 가 밟는다.
